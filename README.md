# DumpIt — Your Memories, Beautifully Preserved

> Pick a template, upload your photos, and get a beautiful scrapbook you can share and save as PDF.

Live Site: [dumpit.my.id](https://dumpit.my.id)

---

## About

DumpIt is a free, web-based memory scrapbook maker born from a love of preserving moments in a personal and beautiful way. No design skills needed — just upload your photos, choose a template, and create something meaningful.

### Why DumpIt?

- Simple — No learning curve. Just upload and create.
- Private — Your photos, your memories. Always protected.
- Free Forever — No hidden fees. No subscriptions.

## Getting Started

### Prerequisites

- PHP >= 7.4
- Web server (Apache / Nginx)

### Installation

```bash
git clone https://github.com/nelifauziyah88/dumpit.git
cd dumpit
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.
